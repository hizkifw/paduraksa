# API reference

The reference below is rendered from `openapi.v1.json`, the OpenAPI 3.1 document that this version of Paduraksa ships and serves at `/api/v1/openapi.json`. It loads from this site only: nothing is fetched from a third party when you read it.

Every operation names the permission it needs (`x-required-permission`). Read [The REST API](api.md) first for authentication, pagination, `If-Match` and the other conventions that apply to all of them.
